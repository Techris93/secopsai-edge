# MSP Pilot

## Pilot Offer

14-day pilot:

- 1 to 3 customer sites
- software sensor on MacBook, Raspberry Pi, or mini PC
- daily scheduled scans
- weekly executive report
- findings review call
- webhook/email notifications

## Dashboard Workflow

- Sites page: create one site per customer location.
- Schedules page: set per-site daily or weekly scans.
- Findings page: filter by site, severity, and status.
- Reports page: generate per-site reports.
- Settings page: configure notifications and SecOpsAI Core sync.

## Early Pricing Test

- Starter: `$29/site/month`
- Pro: `$99/month` up to 5 sites
- MSP beta: `$199/month` plus per-site pricing

Hardware appliances can be offered later as setup fee plus monthly SaaS.
